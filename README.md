# 棒球殿堂風格 3D 棒球手遊原型

以 Three.js + Vite 開發的 3D 棒球遊戲。專案採階段式開發；目前已完成可重複遊玩的 3D 投打、守備、跑壘與規則核心，並開始接入球隊與比賽模式。

## 技術
- Three.js：3D 球場、球員、球體與攝影機。
- Vite：開發伺服器與正式建置。
- Node.js 內建測試：比賽規則與狀態測試。

## 目前已實作
- 程式化 3D 棒球場、內外野、壘包、界外線、全壘打牆、觀眾席與燈光。
- 投手、打者、捕手、內外野守備球員及跑者模型。
- 全場、打擊、投球、守備、跑壘五種攝影機。
- 多種球種、投手體力與個別投手選擇。
- 3D 投球、瞄準、左鍵揮棒、揮棒動畫、初步擊球物理。
- 自動守備追球、飛球接殺及簡化的滾地球傳一壘流程。
- AI 自動選球種及投球。
- 六支中華職棒風格球隊選擇（使用原創隊徽縮寫，不冒用官方素材）。
- 快速比賽、職業聯賽、季後賽、系列賽與球員培養賽入口。
- 自動比賽模式：雙方 AI 會實際執行投球、揮棒、擊球與九局規則流程。
- 球員卡能力面板，顯示球速、控球、等級與即時體力。
- 球員培養：球速訓練、控球訓練、體能恢復、經驗升級與訓練點；資料保存於瀏覽器。
- 即時音效：投球、揮棒、捕球、出局、安打與全壘打事件音效；可由右上角按鈕開關並保存設定。
- 平衡與穩定性修正：長打與全壘打需要更高品質的擊球，連續相同事件仍會正確播放音效，培養存檔會自動校正異常數值。
- 真實感守備移動：守備員依擊球落點選擇合理路線，加入反應延遲、預判落點、加速追球、減速對位與接球前收球姿勢。
- 正式九人守備：投手、捕手、一壘手、二壘手、三壘手、游擊手、左外野手、中外野手、右外野手。
- 好壞球依實際球路在本壘板前的穿越座標判定，並在操作面板明確顯示「好球」或「壞球」。
- 守備站位調整為真實比例的內野菱形與外野扇形；主隊守備球衣與客隊打擊球衣會跟隨選定球隊顏色更新。
- 守備修正：守備員持續追蹤滾地球與飛球，接球判定提前覆蓋低位球，並在每個新打席重置回守備站位。
- 外野守備修正：深遠飛球會由左、中、右外野手負責，避免內野手錯誤搶球；擊球提示會顯示目前追球的守備位置。
- 即時比分、局數、好壞球、出局數與壘包顯示。
- 桌面滑鼠／鍵盤及響應式介面。

## 本次補強：比賽規則核心
- 3 好球出局、4 壞球保送、2 好球後界外球不增加好球。
- 保送時只推進被迫前進的跑者；滿壘保送得分。
- 一壘、二壘、三壘與全壘打的跑者推進及得分。
- 三出局交換攻守、九局結束、延長賽與主隊提前結束下半局。
- 九局下半或延長賽下半的再見安打、全壘打及保送。
- 高飛犧牲打的基本計分與出局處理。

## 本機啟動
需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

## 測試及建置
```bash
npm test
npm run build
npm run preview
```

## 操作
- 點擊「投球」或按 `P`：投球。
- 在球場畫面移動滑鼠：調整瞄準。
- 在球場畫面按滑鼠左鍵、點擊「揮棒」或按空白鍵：揮棒。
- 點擊視角按鈕或按 `1` 至 `5`：切換攝影機。
- 右上角按鈕：切換全螢幕。
- 在「模式與球隊設定」選擇六隊與模式後按「套用賽事設定」。
- 「自動比賽」會讓雙方 AI 進行完整的實際投打流程，可用於觀察規則與 3D 物理。
- 球員卡的訓練按鈕會消耗訓練點；完成一場比賽會獲得訓練點，資料會保存於同一瀏覽器。
- 第一次點擊投球、揮棒或右上角音效按鈕後，瀏覽器會啟用音效；若裝置限制自動播放，請先點擊音效按鈕。

## 開發原則
先完成可重複遊玩的核心比賽流程，再逐步增加跑壘、守備、AI、球隊與模式。每個階段都要通過建置與規則測試；只有已實際實作的功能才列入「目前已實作」。
