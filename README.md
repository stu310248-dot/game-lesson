# 鑽石棒球場 3D

第一階段：可操作的 3D 棒球場與投打練習原型。使用 Three.js 建立場景，Vite 負責本機開發與正式建置。

## 功能
- 程式化 3D 棒球場：外野草皮、內野、壘包、界外線、全壘打牆、觀眾席、燈柱與休息區。
- 程式化球員模型：投手、打者、捕手及八名守備球員。
- 五種攝影機：全場、打擊、投球、守備、跑壘。
- 投球：球體由投手丘飛向本壘。
- 打擊：可操作揮棒，依揮棒時機判定擊球或揮空。
- 擊球：球體具備初步重力、反彈及飛行效果。
- 即時好壞球與出局數顯示（目前為練習模式計數，並非完整正式規則）。
- 桌面鍵盤及手機響應式控制介面。

## 本機啟動
需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可遊玩。

## 正式建置
```bash
npm run build
npm run preview
```

## 操作
- 點擊「投球」或按 `P`：投球。
- 點擊「揮棒」或按空白鍵：揮棒。
- 點擊視角按鈕或按 `1` 至 `5`：切換攝影機。
- 點擊右上角按鈕：切換全螢幕。

## 開發階段說明
這是第一階段可互動原型，並非已完成的完整棒球比賽。正式九局規則、跑壘及盜壘、完整守備 AI、完整球員名單與能力、球隊/聯賽/季後賽模式、音效與完整動畫，將在後續階段逐步開發。球員與球隊目前使用原創示意設定。
